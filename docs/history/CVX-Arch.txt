#Documentation Overview
The ΛΞV docs describe our projects, a platform built from the ground up for scale. 
They cover why ΛΞV system is useful, how to use it, how it works, and why it will continue to grow. 

The goal of the CVX architecture is to demonstrate a set of software algorithms 
that is used in combination to implement a blockchain, removes software as a performance bottleneck, 
allowing transaction throughput to scale proportionally with network bandwidth. 
The architecture goes on to satisfy all three desirable properties of a proper blockchain: it is scalable, secure and decentralized.

The architecture describes a theoretical upper bound of 710 thousand transactions per second (tps) on a standard gigabit network and 28.4 million tps on 40 gigabit. 
Furthermore, the architecture supports safe, concurrent execution of programs authored in general-purpose programming languages such as JS, Python, PHP or C++.
