# Contributing to ALIEV.IO

Thank you for contributing to ALIEV.IO.

## How to contribute
- Create a feature branch from `main`.
- Use descriptive branch names like `feature/auth-improvement` or `fix/security-bug`.
- Keep changes small and incremental.
- Preserve existing behavior when possible.
- Add tests and documentation for significant changes.

## Pull request checklist
- Code is functional and reviewed.
- No secrets are committed.
- Documentation is updated if architecture or configuration changes.
- Existing feature behavior is preserved.
